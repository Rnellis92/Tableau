Tableau Data Visualisation Project
Project Overview

This project was completed as part of a Level 3 Data Technician / Data Analyst bootcamp and focuses on using Tableau to analyse, visualise and communicate data.

The project demonstrates how raw retail and sales data can be transformed into interactive visualisations and dashboards to identify trends, compare performance and support data-driven decision-making.

Visualisations Created

A variety of Tableau chart types were used to explore different aspects of the data, including:

📊 Bar charts – comparing sales and performance across categories
📈 Line charts – identifying trends and changes over time
🥧 Pie charts – showing proportions and category breakdowns
🗺️ Maps – visualising geographical sales and performance
🔢 Calculated fields – creating additional measures and insights from the underlying data
Interactive Dashboards

The individual visualisations were brought together into interactive Tableau dashboards.

Filters and slicers allow users to explore specific sections of the dataset and focus on the information most relevant to them.

This demonstrates how dashboards can move beyond static charts by allowing users to interact with the data and investigate their own questions.

Data Storytelling

A key focus of the project was data storytelling.

Rather than simply creating charts, the visualisations were designed to communicate meaningful information from retail and sales datasets.

The project demonstrates how appropriate chart selection, filtering and dashboard design can help turn complex datasets into information that is easier for a business audience to understand.
